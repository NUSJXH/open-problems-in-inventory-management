# Contributing

Corrections and additions are welcome through GitHub Issues.

## A valid public record

Please provide:

1. the paper title, authors, year, and stable primary-source URL;
2. the exact page, section, theorem, endnote, or conclusion location;
3. one evidence class: explicit conjecture, explicit open question, source-stated extension, or status update;
4. a bounded paraphrase of what the source states;
5. a separate account of what the paper already establishes; and
6. the assumptions, benchmark, or asymptotic regime that limits the statement.

Editorially inferred research ideas are not published as open-problem records. They may be discussed in an issue until a qualifying source statement is identified.

## Status corrections

If a later paper resolves an item, identify the theorem and map its model, information structure, objective, and benchmark to the earlier statement. A result for the best base-stock policy does not automatically resolve a question about the globally optimal dynamic policy.

## Bibliometric data

Trend updates must include the Web of Science Core Collection export, query date, timespan, document types, query strings, unique-accession-number deduplication, and the category assignment rule. Counts from overlapping queries must not be added.
