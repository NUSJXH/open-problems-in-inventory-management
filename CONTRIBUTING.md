# Contributing

We welcome candidate open problems, possible resolutions, source corrections, and challenges to a record's current status.

Please use the structured GitHub Issue form. A useful submission should identify the inventory mechanism, decision, uncertainty, exact research gap, anchor source, source location, known progress, and the search scope used to assess current status.

Submissions enter editorial review. They are not automatically labeled as open problems. Formal-track publication requires an exact source passage, a dated literature audit, and conflict-free expert review.

Do not upload copyrighted article PDFs unless you have permission. Prefer DOI links, publisher pages, preprints, and short quotations with a precise page or section location.
